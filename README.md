# Spaghetti-Place
The Spaghetti Place was a game that I worked on for fun back when I was still active on Scratch. I never ended up finishing it due to a mix of lost motivation and life getting in the way. Even though it's extremely primitive, I'm proud of the few things I made. Click around a bit and see for yourself. 
## How to run
In the Scratch project editor, select **Upload from your computer** from the File tab. Select the project file and import it.
## Controls
- A/D: Change view
- S: Use tool
